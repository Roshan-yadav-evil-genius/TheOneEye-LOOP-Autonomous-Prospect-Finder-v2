# Agent Plans

Implementation plans for LOOP agent runtimes. Each subfolder is one agent architecture pattern.

| Folder | Pattern | Scope |
|--------|---------|--------|
| [AgentWithBrowser/](AgentWithBrowser/README.md) | Orchestrator + Browser + Brain + GPA | Company Finder, Contact Finder, shared deep-agent factory |

Canonical architecture lives in [AgentWithBrowser/00-architecture.md](AgentWithBrowser/00-architecture.md). These plans turn that design into build order, packages, milestones, and acceptance criteria.

**Not in this folder yet:** Verifier agent, automated outreach agents, Company Detail Enricher.
